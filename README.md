# ROC Curve Lab

An interactive study guide for §5.1.3 of Kevin P. Murphy, *Probabilistic Machine Learning: An Introduction* (ROC curves).

**Live:** https://isaackrallison.github.io/roc-curve/

Drag the threshold and watch the ROC point move, calculate an ROC curve by hand, sort out TPR/FPR/TNR/FNR, and take a quiz.

Single self-contained `index.html`, no build step.
